# Security policy

solar-kiosk is made for a home network. What it stores, how sign-in works, the risks that remain, and why we
think they're reasonable for a home app are explained in [docs/security.md](docs/security.md).

## Reporting a vulnerability

Please report security problems **privately**: on this repository's **Security** tab, choose
**Report a vulnerability**. Please don't open a public issue for them.

Helpful to include: what you found, how to reproduce it, and what someone could do with it. Please leave out
your own logins, addresses, serial numbers and other personal details.

## Supported versions

Only the latest release gets security fixes. Installs that update themselves pick fixes up automatically.
